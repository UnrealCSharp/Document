##

### 源码
    - [leanclr](https://github.com/focus-creative-games/leanclr)

---

### Windows
    1. 环境：Visual Studio，CMake 3.15 及以上
    2. 编译选项：[ue](https://github.com/crazytuzi/backend-leanclr/tree/ue)
    3. 编译
        - Debug：`scripts\build.bat runtime -os windows -c debug`
        - Release：`scripts\build.bat runtime -os windows -c release`
    4. include
        - `src/runtime`
    5. dll
        - [Microsoft.NETCore.App.Runtime.win-x64](https://www.nuget.org/packages/Microsoft.NETCore.App.Runtime.win-x64/10.0.4)，修改后缀为.zip，并解压
        - 根据`runtimes/win-x64/lib/net10.0`筛选`artifacts/bin/runtime/net10.0-windows-Release-x64`中的dll
        - `artifacts/bin/coreclr/windows.x64.Release/System.Private.CoreLib.dll`
    6. lib
        - `out/cmake/runtime/Release-x64/Release`
            - `leanclr.lib`
